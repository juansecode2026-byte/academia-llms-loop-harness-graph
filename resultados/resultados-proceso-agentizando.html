1Cómo usar este documento

  1. Un tema solo se agentiza cuando su versión manual está cerrada en el documento manual (misma numeración).
  2. Cada tema enlaza a su sección manual, tiene un checklist de 6 pasos y un bloque para guardar el brief usado y el resultado.
  3. Las casillas se guardan en este navegador; para dejarlas como prueba en GitHub se agrega checked en el HTML y se hace commit.
  4. Regla del laboratorio: si algo se repite, no se convierte en agente sobre la marcha — se anota como candidato en DECISIONES.md (sección 9).
