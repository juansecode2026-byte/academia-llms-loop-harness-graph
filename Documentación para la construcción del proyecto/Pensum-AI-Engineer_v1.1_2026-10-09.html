Cómo usar este pensum

Cómo usar este pensum

  1. Orden sugerido: Python + SQL → APIs → LLMs → Prompt Engineering → RAG → AI Agents → JavaScript → TypeScript → GenAI → Machine Learning → AWS / Azure (escoge una nube primero). Java, Go y R solo si tu trabajo o clientes lo exigen.
  2. No avances de nivel sin terminar el proyecto del nivel anterior: el proyecto es la prueba, no el curso.
  3. Combina habilidades: a partir del Nivel 2, cada proyecto debería usar al menos dos habilidades del pensum.
  4. Publica todo en GitHub con README claro: es tu portafolio y alimenta tu hoja de vida.
  5. Los tiempos son estimados para ~10 horas de estudio por semana.
